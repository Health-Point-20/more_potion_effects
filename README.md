## 📖 模组简介

More Potion Effects 是一个为 Minecraft 添加了丰富新状态效果和相关附魔的模组。它扩展了药水酿造机制，并支持完整的自定义配置。

本模组添加了超过 **80 种新状态效果**和**11 种新附魔**。

## ✨ 主要特性

### 🧪 自定义酿造配方系统

支持通过 JSON 配置添加自定义酿造配方：

- 药水可以同时拥有多个状态效果
- 可自定义药水名称和颜色
- 首次启动时自动生成配置文件夹和示例配方
- 合成的药水自动添加到创造模式物品栏
- 兼容 JEI 查看自定义配方

### 🔧 命令系统

```
/force_effect 或 /fe
```

强制效果管理命令，支持强制添加/移除效果（无视免疫）

### ⚙️ 配置选项

配置文件位于 `.minecraft/config/more_potion_effects.toml`

#### 附魔配置 (Enchantment)
- `Source of Blessing` - 是否启用赐福之源附魔
- `Source of Curses` - 是否启用诅咒之源附魔
- `Source of Blessing Probability` - 祝福之源触发概率
- `Source of Curses Probability` - 诅咒之源触发概率
- `Elimination Effect Probability` - 破法附魔消除效果的概率
- `Sunder Armor Probability` - 破甲附魔触发概率
- `Administer Poison Probability` - 剧毒之刃施加剧毒效果的几率
- `Infliction Corrosion Probability` - 腐败施加施加腐蚀效果的几率
- `Inhibit Therapy Probability` - 抑疗施加弱效恢复效果的几率

#### 效果配置 (Effects)
- `Random Effect Exclusion` - 不会被随机效果抽取到的效果列表
- `Extension_method` - 延时效果模式（0：增加时长；1：轮流消耗）
- `Evasion Probability` - 每级闪避提供的闪避概率
- `Huge Force Damage` - 每级巨力增加的伤害百分比
- `Leeching Health` - 每级吸血增加的吸血量百分比
- `Strong Heart Recovery` - 每级强心提升的恢复生命值
- 更多伤害相关配置项...

#### 病毒配置 (Virus)
- `Virus Base Radius` - 病毒效果基础传染半径
- `Virus Infection Speed` - 病毒感染进度累积基础速度
- `Virus Threshold Factor` - 感染阈值系数
- `Virus Damage Factor` - 伤害系数

#### 死亡配置 (Death)
- `Super Death Mode` - 是否启用超级死亡模式（高等级死亡效果会移除实体）

#### 位格配置 (Rank)
- `Rank Effects Enabled` - 是否为非玩家实体添加随机效果池效果

#### 腐蚀配置 (Corrosion)
- `Super Corrosion` - 是否启用超级腐蚀模式（可以完全摧毁装备）

#### 特殊配置 (Special)
- `Ban List` - 禁用的药水效果列表
- `Force effects` - 能被强行添加到生物的效果列表
- `Entity List` - 强行使列表中的生物能被添加药水效果
- `Upgrade Exclusion` - 升级效果不会升级的效果列表
- `Negative Potion Antagonism` - 药水拮抗是否对负面效果生效

#### 免疫配置 (Immune)
- `Immune Effects` - 免疫效果所能免疫的效果列表（每行对应一级免疫）
